The problem

Changing a file should not be a project.

Turning a photo into a PDF or shrinking a video usually means leaving what you are doing, finding a converter, and often uploading your file to a website you know nothing about.

Without Orange

  1. Find the file in Explorer.
  2. Open a converter app or website.
  3. Upload or import the file.
  4. Pick a format and settings.
  5. Wait, then download or export.
  6. Find the new file and move it where you want it.

With Orange

  1. Drag the file.
  2. Tap Shift, Ctrl or Alt.
  3. Drop it on what you want.

The result is saved next to the original. Nothing leaves your PC.

Features

One gesture. Three wheels.

Shift248

Conversions

Images, video, audio, PDFs, documents, slides, spreadsheets, subtitles and archives. The wheel lists what your file can become, most useful first.

Ctrl26

Tools

Crop, redact, compress, trim, merge, annotate and more. When a tool needs a decision, a small dialog opens with a live preview.

Alt6

Actions

Share, float to a shelf, copy, move, copy the path, or open a terminal in that folder.

  • Drag several files at onceWith two or more files, the merge, collage and PDF tools appear.
  • Saves where you chooseNext to the original, or always in one folder you pick.
  • Lives in the trayStart it with Windows if you like. Settings are one click away.
  • Tells you when it is doneA notification, and a Show button on the recent jobs list.
  • Your keys, your sizePick which key opens which wheel, and set the wheel size and theme.
  • Nothing to install firstThe conversion programs are inside the installer. LibreOffice is offered at setup.

These numbers come from the program itself: run orange counts to see yours. Mac-only formats such as Pages and RTFD are not supported.

Careful by default

Your files stay yours.

Works offline

No account, no uploads. Everything is processed on your PC.

Never overwrites

Results are saved next to the original, with a number added if the name is taken.

Real redaction

The Redact tool destroys the covered pixels in a new copy and strips its metadata.

Build it from source

You need Rust (stable), Node 22, the Visual Studio C++ build tools and the WebView2 runtime. It is a Tauri 2 app: Rust for the engine and the Windows layer, TypeScript for the wheel and dialogs.

# from the project folder, in PowerShell
.\scripts\fetch-deps.ps1
npm --prefix ui install
cargo install tauri-cli --version "^2" --locked
cd src-tauri
cargo tauri build # installers land in target\release\bundle
