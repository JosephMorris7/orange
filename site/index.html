How it works

Nothing to open. The menu comes to the file.

Orange runs quietly in the tray. While you are holding a file, one key tap brings up a wheel at the pointer.

photo.jpg

Start dragging

Pick up any file or folder in Explorer, on the desktop or in another app, and keep the mouse button down.

ShiftConvert
CtrlTools
AltActions

Tap a key

Shift opens formats, Ctrl opens tools and Alt opens actions. You can change the keys in Settings.

Drop on a wedge

Release over the choice you want and it runs. A small dialog opens only when a tool needs your input. Esc cancels.

Offline and careful

Your files stay on your PC

What Orange does

  • Works offline. Orange makes no network connections of its own and has no account or sign-in.
  • Never overwrites. Results are saved next to the original. You can choose one output folder instead.
  • Redaction is real. Covered pixels are destroyed in the new copy, and its metadata is removed.
  • Stays out of the way. It lives in the tray. Closing the settings window leaves it listening for drags.

Good to know

  • Face and text finding in Redact uses recognition built into Windows, so it depends on the language packs you have installed.
  • Word, Excel and PowerPoint files need LibreOffice. Setup offers to install it, and Settings has a button for it later. That download comes from LibreOffice, not from Orange.
  • Early software. The status list below says which parts have been tried the most.

Get Orange

Download, install, drag a file

One installer for Windows 10 and 11 (64-bit). It includes the conversion programs, so there is nothing else to set up.

Download for Windowsfrom GitHub Releases View the source

Install in three steps

  1. Download the installer. It is the file ending in -setup.exe.
  2. Open it. If Windows says it protected your PC, choose More info, then Run anyway. The installer is not signed yet, so Windows does not recognise it.
  3. Drag a file and tap Shift. The wheel opens under your cursor. The tray icon is where you find Settings.

Where it stands

Early release. Tried by hand on Windows 11 (64-bit). Other Windows versions and unusual screen setups have not been tested.
Well covered. Conversions and tools have automated end-to-end tests that run the real programs.
Least tried. The Windows share sheet, text and face finding, and the LibreOffice step at setup.
Found a problem? Tell me on GitHub. Include the file %APPDATA%\Orange\orange.log.
Build it from source

You need Rust (stable), Node 22, the Visual Studio C++ build tools and the WebView2 runtime that ships with Windows 11. It is a Tauri 2 app: Rust for the engine and the Windows layer, TypeScript for the wheel and dialogs.

# from the project folder, in PowerShell
.\scripts\fetch-deps.ps1          # gathers ffmpeg, pandoc, qpdf, ImageMagick, poppler, 7-Zip, exiftool
npm --prefix ui install
cargo install tauri-cli --version "^2" --locked
cd src-tauri
cargo tauri build                 # installers land in target\release\bundle
