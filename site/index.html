How it works

Nothing to open. The menu comes to the file.

Orange runs quietly in the tray. While you are dragging a file, tapping a key brings up a wheel under your cursor.

Step 1

Start dragging

Pick up any file or folder in Explorer, on the desktop, or in another app. Keep the mouse button down.

Step 2

Tap a key

Shift opens formats, Ctrl opens tools, Alt opens actions. The wheel stays open after you let go of the key. You can change the keys in Settings.

Step 3

Drop on a wedge

Release over the choice you want and it runs. A small dialog opens only when a tool needs your input, like cropping. Esc cancels.

The three wheels

Convert, tools, and actions

Each wheel only shows what makes sense for the file you are holding. Choices that need a helper program you have not installed stay greyed out instead of failing later.

Formats

What it can convert

Every source format in a row converts to every target in that row, apart from itself. Orange does the work with well-known open tools and a few small pieces of its own.

KindFromToUses

This build offers 248 source-to-target conversions and 26 tools. The numbers come from the program itself: run orange counts to see yours. Mac-only formats such as Pages and RTFD are not supported.

Offline and careful

Your files stay on your PC

What Orange does

  • Works offline. Orange makes no network connections of its own and has no account or sign-in.
  • Never overwrites. Results are saved next to the original, with a number added if the name is taken. You can choose one output folder instead.
  • Redaction is real. The Redact tool destroys the covered pixels in a new copy and strips its metadata.
  • Stays out of the way. It is a tray app. Closing the settings window leaves it listening for drags.

What to know

  • Face and text finding in Redact uses the recognition built into Windows, so it depends on the language packs you have installed.
  • Word, Excel and PowerPoint files need LibreOffice installed. It is large, so Orange does not bundle it.
  • Some formats depend on your helpers. For example, HEIC output needs an ImageMagick build that can write it.
  • Early software. See the status of each part below before you rely on it.

Build it

From source to tray in a few commands

You need Rust (stable), Node 22, the Visual Studio C++ build tools, and the WebView2 runtime that ships with Windows 11. The project is a Tauri 2 app: Rust for the engine and the Windows layer, TypeScript for the wheel and dialogs.

# from the project folder, in PowerShell
.\scripts\fetch-deps.ps1          # download ffmpeg, ImageMagick, pandoc, qpdf, poppler
npm --prefix ui install
cargo install tauri-cli --version "^2" --locked
cd src-tauri
cargo tauri build                 # installers land in target\release\bundle
